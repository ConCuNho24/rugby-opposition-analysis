\# Rugby Opposition Analysis



QUT Capstone project focused on accelerating opposition analysis in professional rugby.



\## Repository Structure



\### contributions/

Individual work completed by each team member.



Each member has their own folder containing:

\- code

\- weekly contributions

\- reports

\- notes



\### source-code/

Official team source code agreed and integrated by the team.



\### meetings/

Meeting notes and action items.



\### reports/

Shared team reports and project documentation.



\### research/

Research, references and investigation notes.



\### deliverables/

Final or submitted project deliverables.
